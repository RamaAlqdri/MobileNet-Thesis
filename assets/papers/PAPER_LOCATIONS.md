# Lokasi PDF lokal

Korpus awal berada di `Paper/` relatif terhadap root vault. Setiap baris [[02-Literature/PAPER_INVENTORY]] memberi tautan ke PDF asli dan catatan Paper ID. Folder ini menyimpan rujukan lokasi. Gunakan `assets/papers/` juga jika ada PDF baru yang sengaja ditempatkan di sini.

Git mengecualikan PDF. Tautan sumber memerlukan berkas asli pada path yang tercatat dalam salinan vault yang digunakan. Untuk sumber lokal di luar vault, catat path seperlunya di catatan privat, dengan Paper ID sebagai penghubung.
