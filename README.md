## Membuka vault

Di Obsidian, pilih **Open folder as vault**, pilih direktori ini (`MobileNet/`), lalu buka [[HOME|dashboard]]. Gunakan Wikilinks dan fitur bawaan Obsidian. Jika fitur **Templates** dan **Daily notes** diaktifkan, pengaturannya menunjuk ke `templates/` dan `logs/` dalam vault. Template juga dapat disalin langsung.
