# D001 — Lokasi dan identitas korpus awal

Pada 2026-11-23, agent memakai `Paper/` sebagai lokasi sumber karena 29 PDF asli sudah berada di dalam root vault. Git mengecualikan direktori tersebut. `assets/papers/` menyimpan petunjuk sumber. Cara ini memungkinkan Wikilinks lokal dan mempertahankan versi PDF asli.

Paper ID awal mengikuti urutan alfabetis path tanpa membedakan kapitalisasi. ID yang sudah diberikan tetap dipakai saat antrean berubah atau sumber baru ditambahkan. Untuk berkas identik, catat path alternatif pada ID yang sama. Untuk konflik metadata atau varian terbit, catat hubungan versi sebelum memutuskan penggabungan.
